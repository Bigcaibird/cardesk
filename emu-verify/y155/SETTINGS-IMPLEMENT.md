## 二、三项各归其位

### 2.1 「自动导航投屏」—— 删掉

- 偏好键 `start_navi_cast_enabled`；
- 全仓没有任何代码读它 —— 开机流程（`BootReceiver`）、`MainActivity` 都不引用它，
  **从头到尾就没有「导航投屏」这个动作**；
- 跟另外两项不同，它**没有实现可以接**（那两项是「有行为、没开关」或「有开关、没接线」），
  所以只能删。

落盘键仍保留在 `Prefs.kt`，将来真要做这个功能时可以直接接回去。

### 2.2 「桌面开机启动」—— 实现

**之前为什么是「假的」**：它写进 `desktop_boot_autostart` 就没人读。

**但功能其实一直存在**：`BootReceiver` 开机时**无条件**显式拉一次桌面 Activity
（`BootReceiver.kt` 的类注释写得很清楚：「作为 HOME 应用的兜底，部分车机不主动 re-launch HOME」）。
也就是说 —— **行为一直在，只是没有开关管它**。

现在的语义：

| 开关 | 开机行为 |
|---|---|
| 开（**默认**） | 开机广播照旧拉起桌面 —— 跟今天**一字不差** |
| 关 | 开机广播**不**显式拉桌面（车机自己会拉 HOME 的话，用户看到的还是桌面） |

**默认值取 `true` 是刻意的**：这个键以前没人读、`BootReceiver` 是无条件拉桌面的。
如果默认值取 `false`，等于「一升级，开机不拉桌面了」—— 那是回归，不是功能。

**全局 Dock 不受这个开关影响**：`GlobalDockService` 是独立的前台服务，
开机必须常驻（否则用户直接开导航时底栏缺位），它有自己的开关（`globalDockEnabled`）。

### 2.3 「胎压数字字号」—— 实现

**之前为什么是「假的」**：字号在渲染里**写死成 `28f`**，滑杆写进偏好没人读。

**接上之后**：

```
设置页滑杆 → prefs.deskTpmsValueSp → LauncherView.refresh()
           → scenePage.tpmsValueSp → ScenePage.drawTireCard 的 text.textSize
```

- `ScenePage` 新增 `var tpmsValueSp: Int`（setter 里 `invalidate()`）；
- `drawTireCard` 里那四处写死的 `28f` 换成 `tpmsValueSp.toFloat()`；
- 拖动时 `sliderRow` 会触发 `onApply` → `onSettingsApplied()` → `refresh()`，
  所以**拖动过程中桌面上的胎压数字实时变大变小**。

**默认值从 20 改成 28**：这个键之前只写不读，渲染里写死的是 28。
接上以后默认值要是还留 20，等于给所有老用户「悄悄换了个胎压字号」——
用户没动过任何设置，画面却变了。改成 28 之后，**不动这个设置的人画面跟今天一模一样**。

**单位「kPa」不跟着缩**：它是 14px 的**标注**不是数据，跟着放大就糊成一团。
数字变大后，单位位置仍按「量出来的实际宽度 + 8px」算（第三十七轮修过的问题，不能退回去）。

## 三、顺带拆掉的：「暂不可用」机制本身

第154轮为了「保留位置但明说不可用」，加了两条辅助方法：

- `unavailableRow()` —— 右侧淡字写「暂不可用」+ 点整行弹 Toast + 不写偏好；
- `unavailableSliderRow()` —— 同上，但滑杆禁用；
- 以及给状态文字打的 `UNAVAILABLE_MARK` 标记（供测试精确定位）。

这一轮三项全部归位后，**这两条方法一个调用者都没有了**。
留着就是没人调用的死代码（而且没有测试覆盖），所以一并拆掉。

设计上的结论保留在第154轮的审计报告里 —— 将来再遇到「有位置价值但没实现」的项，
照着那套做法来：右侧状态文字（不挤副标题那个池子）、点了只提示、**不写偏好**。

### 两个量化结论

**① 默认值改动对老用户零影响 —— 逐像素完全一致**

新构建把 `desk_tpms_value_sp` 的默认值从 20 改成 28（跟实现前写死的那个值对齐）。
把**旧构建**和**新构建**的胎压卡区域（1105,760)-(1470,915) 逐像素比对：

```
不同像素数 = 0 / 56575，最大通道差 = 0
```

**完全一样**。也就是说：接上一个开关之后，**没动过这个设置的老用户，画面一个字都没变**。

**② 字号真的接到了渲染上**

28 px 与 43 px 两张胎压卡相减，变化像素 **5250 / 56575 = 9.3%** —— 数字整块重画了，
而不是只挪了位置。

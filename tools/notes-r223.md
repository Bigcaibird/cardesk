状态栏那几个白色的胶囊，在深色壁纸上太扎眼了 —— 现在也跟着壁纸明暗换了

一、这次更新了什么
- 顶栏那几个**圆角胶囊**（左边的「驾驶模式」、右边的「城市名」和「温度」），
  以前底色是死的**白色**，压在一张深色壁纸上就像几块白疙瘩，很突兀；
- 现在它们和其它元素一样，**按壁纸的实际明暗自动换一套**：
  壁纸暗 → 换成夜间那套（深色底板 `#171A22` + 描边 `#333947` + 浅色文字）；
  壁纸亮 → 保持日间那套（浅色底板 `#F2F5F9` + 描边 `#D5DBE5` + 深色文字）；
- 顶栏正中的**翻页圆点条**也一起换了 —— 它和那三个胶囊是同一行、同一种材质，
  留着不变的话中间还是一块白。

二、怎么用
- 什么都不用做，**自动生效**。
- 换壁纸（导入照片 / 切预设 / 开视频或动态壁纸）时立刻跟着变。

三、几个细节
- **底板和文字是成套换的**：底板变深了，里面的字就一定变浅，
  不会出现「深底深字」照样看不见的情况。
- **默认场景一个像素都没变**：白天配浅色壁纸、夜间配深色壁纸，
  胶囊的底色、描边、字色都和以前**逐字相同**。
- **只改压在壁纸上的这几个胶囊**：卡片、抽屉、设置弹层、底部 Dock 上的胶囊
  底色由主题定，跟壁纸明暗无关，保持原样（不受影响）。
- 顶栏左边的设置按钮（青色方块）也保持原样。

四、实测（API 28 模拟器，日间 + 暗色壁纸，同一台机器换包对比）
- 三个胶囊底板：**`#F2F5F9`（白）→ `#171A22`（夜间深底）**
- 胶囊内文字：**`#191C23`（深）→ `#EDEFF3`（浅）**，文字与底板对比度 15.1
- 翻页圆点条底板：**`#F2F5F9` → `#171A22`**
- 单测 2602 项全绿。

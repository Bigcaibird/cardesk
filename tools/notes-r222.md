日间模式用暗色壁纸时，状态栏和天气看不清了 —— 现在会按壁纸明暗自动换字色

一、这次更新了什么
- 日间模式下，如果壁纸是**深色的**（自己导入的暗色照片、视频壁纸、动态壁纸），
  顶栏的**时间 / 油量 / 信号图标**、右上角的**天气温度和天气描述**、
  屏幕中间的**歌词**，以前是深色字压深色背景，基本看不见；
- 现在这些元素会**按壁纸的实际明暗自动换颜色**：
  壁纸暗 → 换成浅色字；壁纸亮 → 保持深色字。
  不用加描边、不用加底衬，界面还是原来那个样子，只是字看得清了。

二、怎么用
- 什么都不用做，**自动生效**。
- 换壁纸（导入照片 / 切预设 / 开视频或动态壁纸）时立刻跟着变。
- 日夜模式照旧：高德 / 时间 / 光感三档来源都不受影响。

三、几个细节
- **默认场景一个像素都没变**：白天配浅色壁纸、夜间配深色壁纸，
  字色和以前逐字相同（白天仍是 `#191C23`，夜里仍是 `#EDEFF3`）。
- **带底板的元素不受影响**：驾驶模式胶囊、位置/天气胶囊、卡片、底部 Dock
  —— 它们的底色由主题定，跟壁纸明暗无关，所以保持原样。
- 中间那块歌词和顶栏右边是**分开判断**的：
  上亮下暗的壁纸，顶部按亮底选深字，中间按暗底选浅字，不会有一半看不清。
- 视频壁纸的画面在独立图层上，系统是直接拷视频自己的画面来算亮度，
  每 3 秒更新一次，跟着画面明暗变。

四、实测（API 28 模拟器，日间 + 暗色壁纸）
- 顶栏时钟：对比度 **1.01 → 14.69**
- 顶栏油量 %：**1.01 → 14.69**
- 右上天气大数字：**1.06 → 14.38**
- 右上天气描述：2.42 → **6.85**
- 静态 / 自定义 / 动态 / 视频四种壁纸都实测过，
  领克 AAOS 820A 模拟器上的系统包结果逐项一致。
- 单测 2596 项全绿。

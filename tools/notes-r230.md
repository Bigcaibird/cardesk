# CarDesk 4307 / 1.0.1211-system

## 修了什么

**车机上「导入静态壁纸」只弹一句「没有可用的图片选择器」，根本没法换壁纸。**

原因是这条路上只有一个动作：发一个「打开文档、只要图片」的系统请求，
发不出去就弹提示。车机上没有相册、也没有系统的文件浏览器接管这个请求，
所以这条提示在车上是**必然**出现的 —— 跟视频壁纸第 218 轮遇到的是同一堵墙。

现在改成三层：

1. **先找系统选择器**：依次试「打开文档（只要图片）」「打开文档（不限类型）」
   「取内容（只要图片）」，哪个能用用哪个；
2. **都不行就打开车机自己的图片列表**（应用内），带缩略图，点一张就导入；
3. **取文件地址的多级兜底**：车机文件管理器返回的结果常常只带一部分信息，
   现在三级都试过才认失败。

## 怎么用

- 有系统选择器：设置 → 壁纸 → 导入图片 → 选一张。
- 没有系统选择器：点「导入图片」会直接打开车机里的图片列表：
  - 列表来自 `Pictures` / `DCIM` / `Download` / `Download/CarDesk`；
  - 想放新图：设置 → 局域网传输 → 手机扫码上传，传完回列表点「重新扫描」；
  - 列表里也可以再点「用系统选择器」试一次系统那条路。

## 细节

- 图片按「最新在前」排，最多列 200 张，最多往下找两层目录。
- 支持 `jpg / jpeg / png / webp / bmp / heic / heif`；
  **刻意不支持 gif** —— 静态壁纸只取一帧，放进来会让人误以为会动。
- 选择器最后一档「取内容 + 不限类型」**故意不用**：模拟器实测这一档会被任意应用接管
  （实测跳到音乐播放器），比「没有选择器」更糟。
- 导入流程仍是原来那条：后台解码 → 落盘 → 立刻切过去 → 刷新设置页预览。

## 验证

模拟器（cardesk28，API 28，平台签名）实测：

| 场景 | 结果 |
|---|---|
| 系统选择器可用 | 直接打开系统图片选择器（`documentsui`） |
| 停用相册 + 系统文件浏览器 | 自动打开应用内列表，列出 1 张测试图（缩略图 + 大小 + 日期 + 路径） |
| 在应用内列表里点一张 | 导入成功（`自定义壁纸已导入 srcW=1600 srcH=900`），桌面立刻换成该图 |
| 单测 | 2628 + 新增 15 条（图片库 8 + 选择器 7）全部通过 |

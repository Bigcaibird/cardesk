# 第三百二十轮：Dock 文字放大 + 图标统一 72×72

## 一、背景

用户上机反馈两处观感问题：

1. Dock 音乐播放卡里的歌名、歌手名太小；
2. 空调温度胶囊下方的主驾 / 副驾文字太小；
3. Dock 里除 home 以外的图标都比 home 按钮小，希望**所有图标和 home 按钮一样大**。

第 3 点是硬约束：home 键一直是 72×72 的底板方块，其余图标是 32 左右的裸字形、
右侧 5 枚功能键是 56 的方块。全部做到 72 之后，右侧 5 键 + A/C·AUTO 的横向空间不够
（需要 392px、原来只有 337），因此整条 Dock 必须重排。

## 二、改动

### 1. 文字放大（`ui/shell/DockBarView.kt`）

| 位置 | 原来 | 现在 |
|---|---|---|
| 媒体卡歌名 | 15 粗 | **19 粗** |
| 媒体卡歌手 | 11 弱 | **14 弱** |
| 媒体卡滑动预览的两行 | 15 / 11 | **19 / 14** |
| 温度胶囊「主驾 / 副驾」 | 11 | **14** |
| A/C、AUTO 胶囊文字 | 15 | **17** |

### 2. 图标统一 72×72

| 控件 | 原来 | 现在 |
|---|---|---|
| home 底板 | 72 | 72（不变，作为基准） |
| 应用抽屉键 | 32 宫格 | 72 命中块 + 宫格 8→**12**、间距 4→**6**（总宽 48） |
| 分屏键 | 14×26 两块 | 44×40 两块（描边 2.4→3.2） |
| 360 键 | 38×26 框 + 15 字 | 56×40 框 + **22** 字（描边 1.8→2.6，圆角 10→14） |
| 电源键 | 26 圆 | 40×48（描边 2.6→3.4，竖线 17→24） |
| 风量键 | 56 底板 | **72** 底板 + 图标等比放大 1.28 倍（档位点 pitch 5.4→6.2） |
| 右侧 5 键 | 56 方块 / 圆角 18 | **72** 方块 / 圆角 24（应用图标 44→56） |
| A/C、AUTO 胶囊 | 高 44 | 高 **56** |

命中区同步放大：导航键 / 电源 / 风量 / 右侧 5 键都按 72 注册
（原来统一按 `HIT_MIN = 56`），避免"看得见但点不准"。

### 3. 整条 Dock 重排（设计坐标，1:1 画板）

| 元素 | 原来 | 现在 |
|---|---|---|
| 应用抽屉键中心 | 148 | 146 |
| 分屏键中心 | 220 | 228 |
| 360 键中心 | 316 | 310 |
| 媒体卡 | x365 / 宽 370 | x356 / 宽 **390** |
| 电源键中心 | 805 | 792 |
| 主驾温度胶囊 | x845 | x838 |
| 风量键 | x1082 | x1053 |
| 副驾温度胶囊 | x1166 | x1135 |
| A/C | x1416 | x1352 |
| AUTO | x1483 | x1418 |
| 右侧 5 键首中心 / 步距 | 1608 / 64 | 1530 / **82** |

重排后最右一枚键的右边缘是 1892，与左侧 home 的 28 左右对称；
每个 72 方块之间留 8~10 的呼吸位，没有重叠。媒体卡加宽 20 用来抵消字号变大后
可见字数变少的问题。

## 三、实测

- `gradle testSystemUnitTest --offline`：**2864 例 / 0 失败 / 0 错误 / 0 跳过**（280 个结果文件）。
- `gradle assembleSystem -PcardeskPackage=com.ecarx.cardesk --offline` 通过，装 `emulator-5572` 后：
  - Dock 全排布与设计坐标一致，最右键右边缘 1892、无重叠；
  - 歌名/歌手、主驾/副驾、A/C·AUTO 字号肉眼可见变大，长歌名按原逻辑省略号裁剪；
  - 空媒体卡仍是「暂无播放」；空调胶囊、温区胶囊数值与档位条都正常。
- 截图：`emu-verify/shots-r320/r320-01-dock-72.png`（发行包实拍桌面 Dock）、
  `r320-02-dock-media-long.png`（临时塞入长歌名/歌手验证放大与裁剪，验证后已还原代码）。

## 四、判据

1. 视觉：home 与其它图标底板同高（72），最右键与最左 home 左右对称。
2. 触控：点四个导航键、电源、风量、右侧 5 键都能命中（命中区 72）。
3. 文字：媒体卡两行、温度胶囊两字、A/C·AUTO 均比上一版大且不出框。
4. 回归：单测 2864 全绿；桌面翻页、设置页、画中画等不因 Dock 重排受影响。

## 五、诚实缺口

1. A/C、AUTO 是文字胶囊不是图标，所以只把高度提到 56、没有做成 72 方块
   （做成 72 会挤掉右侧 5 键的空间，且文字胶囊做成方块并不好看）。
2. 媒体卡仍然只有 390 宽，超长歌名会按原有规则省略号裁剪，可见字数受卡片宽度限制。
3. 只在 1920×1080 车机复原 AVD 上验证；真车 DPI/insets 差异下的观感待上机确认。
4. 未在真车上验证 8~10 的呼吸位在触摸屏上是否会误触邻键（命中区已按 72 注册，
   但相邻命中区仍有交叠，靠插入顺序决定优先级——沿用原有实现）。

音乐卡新增汽水音乐支持 + 未适配音乐 App 的通用兜底，收藏爱心图标放大

一、这次更新了什么
- 音乐卡（第二页导航页）新增「收藏」和「播放模式」两个图标按钮的能力扩展：
  · **新增适配汽水音乐车机版**（此前只适配了 QQ 音乐和网易云）；
  · **未适配的音乐 App 有了通用兜底**：只要它用 Android 标准媒体会话，
    桌面就能自动认出来并给出收藏按钮；
  · 收藏爱心图标**放大了约 43%**（内容区 28×28 → 40×40，点击热区和版式不变）。

二、汽水音乐这次为什么能支持收藏
- 重新检查了汽水车机版（com.luna.music.car）的会话回调，发现它实现了标准的
  「评分」回调：收到心形评分就执行收藏/取消收藏。
- 也就是说：桌面下发**标准心形评分**它就会真的收藏，收藏态也能从会话元数据读回来。
- 汽水的「切换播放模式」仍然没有对外开放通道（只在它自己的进程内指令中心里，
  由语音触发），所以播放模式按钮对汽水是隐藏的。

三、通用兜底怎么工作
- 兜底走的是 Android 官方定义的标准媒体会话入口：
  收藏 = 心形评分，播放模式 = 自定义动作。
- 但不是无脑乱发：桌面会先看这个会话自己发布的事实再决定亮不亮按钮 ——
  · 会话发布了心形评分 → 说明它用标准收藏语义 → 亮收藏按钮；
  · 会话暴露了重复/随机播放模式字段 → 说明它用标准模式语义 → 亮播放模式按钮；
  · 探测不到 → 两个按钮都不亮（亮一个点了没反应的按钮比没有更糟）。

四、顺带修掉的问题
- 网易云音乐收藏后，界面偶尔停在「未收藏」：它的进程内缓存和它发出来的元数据
  可能不一致。现在桌面会接住播放器回报的收藏结果，把状态校正过来；
  真的失败则回滚，不会让界面停在「以为收藏了」。
- 隐藏 API 的会话代理调用抽成了公共层，并兼容了不同 Android 版本上
  评分入口的不同命名。

五、实测（API 28 模拟器，车机真包）
- 汽水音乐：收藏/取消收藏下发成功，收藏态由播放器回报。
- 通用兜底：把汽水从适配表里摘掉后（等价于一个没适配过的音乐 App），
  桌面靠探测照样认出来并能收藏；播放模式按钮仍正确隐藏。
- 网易云音乐：收藏/取消收藏/切换播放模式全部通过。
- QQ 音乐：收藏/播放模式回归通过。
- 单测 2353 项全绿。

# CarDesk 4302 / 1.0.1206-system

## 这一版修了什么

1. **画中画里的高德不再跑到主屏全屏**
   高德进来之后自己会再起一个活动（`MainMapActivity`），那个活动**另建一个 task**、
   不带虚拟屏参数，于是被系统放到主屏上 —— 桌面被盖住、画中画那块变黑。
   这版在「把应用搬到虚拟屏」之后多守一段（约 7 秒，6 次复查），
   一旦发现有活动跑到别的屏上，**优先把它搬回来**，并限制最多搬 3 次防死循环。

2. **左右切首页 / 导航页，画中画不再残留黑块**
   画中画挂在导航页里，切到首页时导航页被隐藏，但承载层的图层不会跟着消失
   （AOSP 9 上祖先隐藏摘不掉独立图层），首页那个位置就留一块黑卡。
   这版在离开导航页时把承载层**整块挪到屏外**（不拆承载面，回来画面还在、应用不重启）。

3. **画中画的圆角回来了**
   圆角丢失的根子是**窗口半透明**：视频壁纸走 `SurfaceView` 后端时必须把窗口设成
   `TRANSLUCENT`，窗口一旦半透明，承载层的图层就不再被窗口轮廓裁剪 —— 圆角变直角，
   而且承载画面与窗口的坐标/裁剪脱节（这就是「高德错乱显示」）。
   这版把视频壁纸的默认后端换回 `TextureView`（窗口保持不透明）：
   实测圆角正常、切页无残留；视频照样能播（第213轮「TextureView 画不上屏」的结论是错的，
   真因是诊断代码抢了 `TextureView` 内部的帧回调，见下）。

4. **去掉「自绘动态壁纸」**
   按你的要求移除。程序化动态壁纸每帧要画满 1920×1080，车机上太卡；
   它同时在壁纸层把所有东西都变得「不透明」，反而掩盖了上面第 3 条的病。
   现在壁纸只有：静态壁纸（含轮播）／导入的视频壁纸。

## 怎么用

- 全部自动生效，没有新开关。
- 如果车机上视频壁纸**发烫 / 掉帧**，可以把 `design_video_wallpaper_backend`
  改成 `0` 换回 `SurfaceView`（硬件直通更省电）——代价是上面的圆角与残留问题会回来。

## 细节

- 守护窗口：搬稳后 0.6s / 0.9s / 1.2s / 1.8s / 2.4s 复查，全程约 7 秒；
  期间又跑到别的屏就立刻搬回，最多 3 次。
- 切页只「挪走」承载层，**不释放**虚拟屏、**不重启**承载应用；切回来是原来的画面。
- 视频壁纸默认后端 `TextureView`；`SurfaceView` 保留为备选（pref 切换）。
- 新增一条每次起播打一行的「视频壁纸诊断」日志，方便后续在车机上排障。

## 验证

- 单测 **2625 / 0 失败**（含新增「守护窗口」用例，删掉的动态壁纸用例 11 条不计）。
- 模拟器（cardesk28 / API 28）：高德配成画中画后，启动 20 秒仍嵌在卡里；
  首页 ⇄ 导航页来回切，首页无黑块、回来高德不重启（`START` 计数 0 次新增）。
- 详细过程见 `emu-verify/REPORT-r225.md`。
